# 인테리어 전자 소품과 모션 장갑 검토

검토일: 2026-09-15. 방향 선택을 위한 기획이며 제작·측정 결과가 아니다. 이전 Air Cue 기획은 다시 채택하지 않았다. 이미지의 치수, 센서 위치, 화면은 콘셉트다.

## 후보 비교

| 후보 | 생활에서 사용하는 장면 | 핵심 제작 과제 | 12주 범위 | LLM의 선택적 역할 |
|---|---|---|---|---|
| 빛 조형 조명 | 소파에서 책을 읽거나 자기 전 조도를 낮출 때 | LED 확산, 가동 차광판, 모터 소음과 발열 | LED 1계통 + 차광판 1축 + 터치·밝기 센서 + BLE 설정 | 자연어를 제한된 조명 프리셋으로 변환 |
| 기억 액자 | 선반에서 그날의 기억과 그림을 보거나 지난 기록을 넘길 때 | 전자종이 구동, 글꼴·그림 전송, 업데이트 상태 | 흑백 전자종이 + 버튼 + BLE 전송 + PC 기록 앱 | 사용자가 입력한 기록을 짧게 요약; 그림 생성은 별도 선택 |
| 살아 있는 북눅 | 책장 앞을 지나거나 문을 터치했을 때 작은 세계가 반응 | 미니어처 설계, 배선 은폐, 한 축의 반복 동작 | LED 3구역 + 문 또는 피규어 1축 + 접근 센서 + 3개 장면 | 준비된 장면 중 선택하고 짧은 이야기를 PC·폰에 표시 |
| 모션 장갑 | 손 모양을 3D로 보고 기록하거나 게임에 입력할 때 | 센서 고정, 사용자별 보정, 손 모델 대응 | 검지 3관절 검증 후 한 손 확장 + BLE + 3D 뷰어 | 핵심 경로에는 불필요; 제스처 이름·명령 편집 보조 |

평가상 실용성을 우선하면 조명, 피규어·3D 프린팅의 재미를 우선하면 북눅, 센서와 무선 기술을 깊게 다루려면 장갑이 적합하다. 12주 내 성공 여부는 조명은 기구·열, 북눅은 조립·소음, 장갑은 초기 센서 반복성 실험에 크게 좌우된다.

## 1. 빛 조형 조명

평소에는 곡선 조형물이고, 저녁에는 고정 LED 앞의 차광판이 움직여 빛의 면적과 그림자를 바꾸는 탁상 조명. 터치로 읽기·휴식·취침 프리셋을 선택한다. 조도 센서는 주변 밝기에 따른 보정에 사용한다. 취침 프리셋은 정해진 시간 동안 서서히 어두워진다.

구성: NU-54V DK, 저전압 LED와 적합한 드라이버, 확산판, 소형 서보 또는 기어모터·드라이버, 터치 입력, 조도 센서, 별도 전원, 3D 프린팅 케이스. LED와 모터 전력은 MCU GPIO로 공급하지 않는다. 첫 버전은 고정 LED와 차광판 1축으로 제한한다. 강한 빛의 패턴이나 프로젝터 수준의 영상은 목표가 아니다.

LLM은 PC·폰에서 동작하며 “30분 뒤 잠들 분위기”를 사전에 정의한 프리셋과 시간으로 변환한다. 수동 터치와 로컬 타이머는 PC 없이 작동하도록 설계한다. LLM 자체를 핵심 구매 이유로 삼지 않는다.

## 2. 기억 액자

사용자가 남긴 짧은 글과 선택한 그림이 하루 한 장의 흑백 엽서처럼 보이는 액자. 버튼으로 이전 기록을 넘긴다. 선반에 놓을 수 있도록 후면에 보드와 전원 공간을 둔다.

구성: NU-54V DK, 드라이버가 포함된 SPI 전자종이 모듈, 버튼, 필요 시 외부 저장장치, 프레임, 전원. 특정 디스플레이 구입 전 3.3V 신호 호환성, MCU 예제, 프레임 버퍼 크기와 갱신 시간을 확인한다. 예를 들어 800×480 1비트 흑백 프레임은 48,000바이트이며, 다른 색 평면이나 버퍼·펌웨어 메모리는 별도다. 큰 비트맵의 BLE 전송에는 분할과 완료 확인이 필요하다.

전자종이는 전원 없이도 마지막 화면을 유지하지만 갱신 속도가 느리고 화면 전환 시 깜빡일 수 있다. 영상·실시간 애니메이션 용도로 기획하지 않는다. 모듈의 갱신·슬립 권장사항을 따른다. 첫 버전은 PC에서 글꼴과 이미지를 렌더링하여 보내는 방식으로 구현 복잡도를 낮춘다.

NU-54V DK에는 Wi-Fi가 내장되어 있지 않다. 새 콘텐츠를 원격으로 받으려면 가까운 PC·폰의 BLE 중계 또는 별도 네트워크 모듈이 필요하다. 중계가 없으면 마지막 콘텐츠를 계속 표시하고 로컬 저장 기록을 넘긴다. LLM은 사용자 입력을 요약하는 선택 기능이며 일상을 자동으로 알고 있다고 가정하지 않는다.

## 3. 살아 있는 북눅

책 사이의 작은 정비소나 오두막. 사람이 다가오면 창문에 불이 켜지고, 문이 열리거나 피규어가 한 번 고개를 내민다. 손으로 터치하면 밤 장면으로 전환한다. 반복 감지로 계속 움직이지 않도록 재생 후 대기 시간을 둔다.

구성: NU-54V DK, 접근 감지 센서(ToF 등의 모듈), LED와 드라이버, 서보 1개, 전원, 자석식 분리 패널 또는 나사식 케이스, 미니어처. 첫 버전은 창문·작업등·배경의 3개 조명 구역과 가동부 1개만 구현한다. 조용한 공간에서는 서보의 작동음이 경험을 해칠 수 있어 초기에 실물 확인한다. 상시 구동보다 접근 시 한 번 움직이는 장면으로 설계한다.

LLM 없이도 3개의 로컬 장면으로 완성한다. LLM을 추가한다면 PC·폰에서 짧은 이야기를 만들고 장면 ID만 보낸다. 그림에는 스피커가 없으며 음성 재생은 기본 범위가 아니다.

## 모션 장갑 이미지의 해석

![모션 장갑 예상 이미지](assets/concepts/motion-glove.png)

손가락 등쪽의 분절된 센서 포켓, 손등 IMU, 팔뚝에 고정한 전자 모듈, PC의 3D 손 화면을 표현했다. 실제 NU-54V DK 사진이나 확정된 회로·봉제 도면이 아니다. 화면은 데이터 연결을 검증한 결과가 아닌 예시다. 이미지에서 센서 위치나 손 모양이 일치해 보여도 측정 정확도를 보증하지 않는다.

처음에는 검지 MCP·PIP·DIP 굽힘을 측정한다. 전체 한 손으로 확장하면 네 손가락 3개씩과 엄지 MCP·IP 2개를 합쳐 14개 굽힘 측정 지점이 된다. 이 구성은 엄지 CMC의 복합 운동이나 손가락 벌림을 모두 측정하지 않는다. 긴 굽힘 센서 5개로 각 관절을 독립 측정한다고 주장하지 않는다.

NU-54V DK의 가용 핀 확인이 필요하며 다수의 아날로그 센서는 외부 ADC 또는 멀티플렉서를 검토한다. 보정·필터링 후 BLE로 전달하고 PC에서 손 뼈대의 회전으로 대응한다. IMU는 손등 회전 추정에 사용하며 단독으로 안정적인 공간 위치를 얻는 구성은 아니다. PC Chrome 뷰어부터 검증하고 모바일 플랫폼은 별도로 확인한다.

## 인테리어 외형 비교

![인테리어 전자 소품 세 가지 예상 이미지](assets/concepts/interior-concepts.png)

왼쪽부터 빛 조형 조명, 기억 액자, 살아 있는 북눅. 모두 제작 전 예상도다. 조명의 실제 조도·발열·그림자 형태, 액자의 디스플레이 규격, 북눅의 내부 장착 공간은 실물 검증 대상이다.

## 인테리어 후보의 12주 진행 예시

- 1~2주: 한 후보 선택, 핵심 부품 하나씩 구동, 실제 크기 모형 만들기.
- 3~4주: NU-54V DK의 센서·출력 통합, 기본 동작 완성.
- 5~6주: 외형·배선·전원 시제품, BLE 설정 또는 콘텐츠 전송.
- 7~8주: 일상 사용 흐름 완성, 필요하다면 PC·폰 LLM 중계 추가.
- 9~10주: 케이스 재설계, 집에서 반복 사용, 소음·발열·연결 문제 수정.
- 11~12주: 최종 조립, 측정·촬영, 부품표와 조립 방법, Medium 원고 정리.
