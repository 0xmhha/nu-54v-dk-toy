# P01 외부 secure element 선택 노트

> **2026-09-29 컷:** 외부 SE를 조달·연결할 시간이 없어 이번 사이클에는 쓰지 않는다. 기기 키는 TrustZone 위 TF-M secure partition에서 만들고 서명한다 [N02]. 아래 1절(4주차 게이트 결과)은 유효하고, 2·3절은 다음 사이클을 위한 기록이다.

[DF-20260925-02](../../planning/design-freeze-checkpoint-02.md)의 4주차 증거 게이트 항목 "외부 SE 데이터시트의 secp256k1 지원 확인"(WBS2-P01-10)의 결과와 결정이다 [N02][N03]. 조사 원본은 study 저장소의 bring-up 기록 10절이다.

## 1. 확인한 것

결제 기기는 secp256k1로 EIP-712 서명을 한다 [N04]. 외부 SE가 이 곡선을 지원하면 키를 SE 안에서 만들고 SE 안에서 서명할 수 있다. 지원하지 않으면 SE는 키를 감싸는 비밀과 재시도 카운터만 맡고 서명은 MCU가 한다. 후보 세 개를 제조사 자료로 확인했다.

| 후보 | secp256k1 | 근거 |
|---|---|---|
| NXP SE050 | 지원. 표 1에서 SE050E2, SE050F2(224비트 이상), SE050A1/A2/D2, SE050C1/C2와 개발 키트(OM-SE050ARD, OM-SE050ARD-E)가 Koblitz 곡선(160~256비트)과 ECDSA를 지원한다. SE050B는 RSA 전용이다 | NXP AN12436 Rev. 2.4 (2024-07-08), 표 1 "SE050 configuration" |
| Infineon OPTIGA Trust M V3 | 지원하지 않는다. NIST P-256/384/521과 Brainpool만 있다 | OPTIGA Trust M 데이터시트 v3.70 |
| TROPIC01 | 지원하지 않는다. P-256 ECDSA와 Ed25519만 있다 | TROPIC01 데이터시트 |

**게이트 판정: 충족.** SE050 계열이 secp256k1 ECDSA를 지원한다는 것을 데이터시트(응용 노트 표 1)로 확인했다.

## 2. 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 부품 | NXP SE050 계열. 1순위 SE050E2(개발 키트 OM-SE050ARD-E), 2순위 SE050C2(OM-SE050ARD) | 둘 다 Koblitz ECDSA를 지원하고 동작 온도가 -40~105 °C다. E2는 표 1에서 Ed25519·Curve25519·Curve448까지 지원해 다음 단계 확장 여지가 크다. FIPS 설정인 F2는 SCP03이 필수이고 224비트 미만 키가 막혀 시험 부담이 커서 제외했다 |
| 연결 버스 | I2C. 1순위 Qwiic 커넥터(J5, `i2c21`) | 보드에 이미 나와 있는 I2C다. PMIC(BQ25186, 주소 0x6A)와 버스를 함께 쓰므로 주소 충돌과 풀업 병렬을 실물에서 확인한다 |
| 키 생성과 서명 위치 | SE 안에서 키를 만들고 SE 안에서 서명한다(2026-09-29 N02 개정) | 개인 키가 MCU 메모리를 지나지 않는다. SE 명령 경로는 TF-M secure partition에만 두어 버튼 토큰 경계를 지킨다. 실물에서 secp256k1 키 생성이 실패하면 TRNG 키를 SE로 감싸는 방식으로 되돌린다 [N02][N24] |
| 조달 | 5주차 안에 개발 키트 1개 주문 | 8주차 보안칩 통합(WBS2-P01-05)까지 도착해야 한다. 8주차에 없으면 컷 순서 1번(SE 제외, TF-M waiver)을 미리 선언한다 [N03][N14] |

## 3. 아직 정하지 않은 것

- **실물 동작.** NXP 커뮤니티에 일부 variant에서 secp256k1 키 생성이 "conditions of use not satisfied"로 실패했다는 보고가 있다. 8주차 첫날 실물로 키 생성과 서명을 먼저 확인한다.
- **SE050 I2C 주소와 MCU–SE 구간 보호(SCP03).** 주소는 개발 키트 문서로 확인하고, 버스 도청 대응(SCP03 세션)은 8주차 설계에서 정한다. 응용 노트에 있는 기본 SCP03 키는 공개된 값이므로 그대로 쓰지 않는다.
