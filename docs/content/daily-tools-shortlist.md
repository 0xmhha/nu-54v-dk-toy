# 실제 사용 장면에 따른 제품 후보

추가 후보: [근접 확인·제스처 기반 코인 결제 지갑과 키오스크](proximity-wallet-kiosk.md). 보드 기능 활용과 결제 UX 시연에는 강점이 있으나, 일상 사용은 지원 키오스크/가맹점 확보에 달려 있다. 테스트넷 시제품과 실자산용 하드웨어 지갑의 완료 기준을 구분한다.

2026-09-15. 사용자가 제시한 보드게임, FPS, PC AI 음성 대화, 빠른 기록, 책상 시계·대시보드를 기준으로 검토했다. 센서 기록기 추천은 사용 목적과 맞지 않아 현재 추천에서 제외한다. 아래는 제안이며 제품 확정이나 구매·구현을 시작한 상태는 아니다.

## 추천: 음성 호출·빠른 기록 기능이 있는 책상 시계

핵심: 작은 화면, 큰 AI 호출 버튼, 별도의 기록 버튼, 회전 다이얼을 가진 탁상 기기. 평소에는 시간과 다음 알람을 보여주고, 버튼으로 PC의 음성 대화를 시작하거나 기록을 남긴다. 하나의 물리적 조작으로 창을 찾고 녹음을 켜는 수고를 줄이는 것이 목표다.

### 사용 흐름

- AI 버튼: 지정한 PC 앱으로 전환한 뒤 지원되는 음성 대화/입력 단축키 실행. 기존 앱의 대화를 사용하는 방식부터 검증한다.
- 기록 버튼: PC 동반 앱이 녹음 시작. 다시 누르면 저장한다. 선택한 모드에 따라 현재 화면 캡처 한 장을 같은 기록에 묶는다. 음성 원본, 전사문, 시각을 연결한다.
- 다이얼: 타이머 시간 조정, 대시보드 페이지 이동, 선택 확인. 일반 시스템 볼륨 조절은 추가 프로필로 검토한다.
- 평소 화면: 시각, 날짜, 다음 알람, 동반 앱이 관리하는 마지막 기록 상태. PC 정보는 갱신 시각과 연결 상태를 표시한다.
- 알람: 보드가 로컬에서 처리. 전원을 유지하는 동안 PC가 꺼져도 동작하도록 설계한다. 전원 제거 후에도 시각을 유지하려면 백업 가능한 RTC 등의 구성이 필요하다.

‘AI 처리 중·완료’ 같은 상태는 연동 인터페이스가 실제 반환할 때만 표시한다. 단축키를 보냈다는 이유로 음성 대화가 켜졌다고 단정하지 않는다. 자체 녹음의 시작·정지·저장 완료는 PC 동반 앱의 응답을 받아 LED와 화면에 표시한다.

### 역할 분담

NU-54V DK: 버튼, 다이얼, 조도 센서, 화면, 알람, BLE 통신. PC: 기존 마이크와 스피커, 음성 앱, 화면 캡처, 파일 저장, 필요한 전사·요약. BLE로 처음에는 명령과 상태를 주고받는다.

부품 후보: NU-54V DK, 소형 SPI 디스플레이, 로터리 인코더, 버튼 2~3개, 상태 LED, 부저와 필요한 구동 회로, 조도 센서, 전원, 케이스. 조도 센서로 밤에 화면을 자동으로 어둡게 한다. 디스플레이는 프레임 버퍼와 부분 갱신을 고려해 선정한다.

제품 가치의 상당 부분은 PC 동반 앱에 있다. 음성 대화 기능 자체는 이미 소프트웨어로 가능하므로 하드웨어가 반드시 필요한 것은 아니다. 큰 전용 버튼·다이얼·항상 보이는 시계가 단축키만 쓰는 것보다 실제로 편한지 초기 일상 사용으로 평가한다.

### AI 음성 연동 조사

- OpenAI 공식 문서는 데스크톱 앱에서 Codex 작업에 대해 Voice를 사용할 수 있다고 설명하며 계정·워크스페이스·배포 상태에 따른 가용성 차이를 명시한다. 음성 단축키 설정도 제공한다. 현재 설치 앱에서 메뉴와 실제 키 동작을 확인해야 한다. [Voice 문서](https://learn.chatgpt.com/docs/features/voice), [명령 문서](https://learn.chatgpt.com/docs/reference/commands)
- Claude 일반 앱의 음성 대화는 웹·데스크톱에서 제공된다. Claude Code와 Cowork에는 이 양방향 음성 모드가 없고 dictation은 제공된다고 공식 도움말이 구분한다. [Claude Voice](https://support.claude.com/en/articles/11101966-use-voice-mode)
- Claude Code CLI는 `/voice`와 누르고 말하기·탭 방식, 한국어, 단축키 재설정을 지원한다. hold 모드 기본값은 텍스트를 넣은 뒤 Enter를 기다린다. tap 모드에는 자동 제출 동작이 있어 동일하게 취급하면 안 된다. [Claude Code 음성 입력](https://code.claude.com/docs/en/voice-dictation)
- Claude Code의 답변을 소리로 읽으려면 별도의 응답 수신·TTS 연동이 필요하다. API로 새 음성 에이전트를 만들면 기존 앱 대화와 자동으로 동일해지지 않으며 별도 인증·사용료·대화 관리가 생길 수 있다.

## 다른 두 후보

### 보드게임 진행 콘솔

중앙 화면 + 참가자별 버튼 + 다이얼. 각자 버튼으로 턴을 넘기고, 개인별 남은 시간·현재 라운드·입력한 점수를 표시한다. 첫 버전은 유선 버튼 4개를 한 보드에 연결하여 추가 무선 보드 없이 완성한다. 타이머와 점수는 로컬에서 동작하고 BLE로 게임 결과를 PC·폰에 기록한다.

완성 목표: 턴 타이머, 점수 카운터, 한 번 되돌리기, 프리셋. 게임 규칙과 점수 계산을 모두 자동 인식하는 범용 심판이나 카메라 기반 카드 인식은 기본 범위가 아니다. 플레이하는 게임에 따라 버튼·점수 흐름을 맞춰야 한다.

### FPS 보조 입력 장치

첫 후보는 왼손 미니 키패드 또는 발로 누르는 2~3버튼 장치다. 키보드·마우스를 사용하면서 음성 채팅, 지도, 웅크리기 같은 사용자가 정한 단일 입력을 분담한다. 신체 자세와 조작 습관에 맞춰 선택한다.

BLE HID를 기반으로 제작할 수 있지만 입력 지연·끊김·게임별 인식은 실제 게임에서 측정해야 한다. 상용 게이밍 장치보다 빠르다고 주장하지 않는다. 경쟁용 초저지연을 최우선으로 한다면 전용 무선 링크·수신기까지 별도 검토가 필요하다. nRF54L15의 PDM/I²S 기능과 Bluetooth 마이크·스피커 호환성은 별개다. [Nordic HID](https://www.nordicsemi.com/Applications/HID), [nRF54L15 주변장치](https://academy.nordicsemi.com/courses/nrf54l-series-express-course/lessons/lesson-3-peripherals-and-system-components/topic/communication-peripherals/)

## 빠른 기록의 확장 경계

- PC 화면: PC에서 캡처한다. 보드 자체가 PC 화면을 읽는 구조가 아니다.
- 지난 수십 초의 게임 영상 저장: PC에서 미리 실행 중인 순환 녹화 기능이 필요하다. 단순 캡처 버튼만으로 과거 영상이 생기지 않는다.
- 외출 위치 기록: 위치를 얻는 폰 앱 또는 별도 GNSS가 필요하다. BLE와 IMU만으로 위도·경도를 얻지 않는다.
- PC 없는 휴대 녹음: PDM 마이크, 외부 저장장치, 배터리 및 음성 전송 프로그램을 추가하는 별도 확장이다. 원시 16kHz·16비트·모노 음성은 1분에 1,920,000바이트라 RAM에 장시간 보관할 수 없다.

## 12주 범위

추천 제품 기준: 1~2주 실제 앱 단축키·BLE 버튼, 3~4주 동반 앱 녹음·저장, 5~6주 화면·시계·알람, 7~8주 선택적 화면 캡처와 기록 묶기, 9~10주 케이스·밝기·연결 복구, 11~12주 일상 사용과 수정·촬영·문서화.

첫 검증 기준은 ‘버튼 한 번으로 원하는 음성 기능이 제대로 열리는가’와 ‘기록이 빠짐없이 저장되는가’다. 기본 음성 동작은 대상 AI 앱 하나와 OS 하나를 정해 완성한다. 대시보드는 1~2개 정보로 제한하고 위치 기록·독립 녹음·범용 게임 연동은 이후 확장으로 둔다.
