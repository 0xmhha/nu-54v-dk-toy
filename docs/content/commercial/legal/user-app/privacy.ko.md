> 검토받지 않은 초안입니다. 법률 자문이 아닙니다. 빈칸은 `publisher.json`에서 채우며, 채우고 검토를 마치기 전에는 외부에 배포하지 않습니다.

## 책임 주체

앱의 개인정보를 책임지는 주체는 {{publisher.name}}이고 문의는 {{publisher.contact}}입니다.

매장 서버는 매장이나 운영자가 운영합니다. 앱에 등록한 매장마다 다를 수 있습니다.

## 앱이 묻지 않는 것

매장 등록과 결제에 이름, 전화번호, 이메일을 묻지 않습니다. 앱에는 광고나 이용 분석 프로그램이 들어 있지 않습니다.

매장은 사용자를 임의로 만든 번호와 인증서로 구분합니다. 이 번호와 지갑 주소는 구매 기록과 이어지므로 개인정보로 다룹니다.

## 휴대전화에 저장하는 것

지갑 기록: 보드 식별값, 보드 계정 주소와 세대, 언어, 동의한 문서의 판과 시각, 선택한 네트워크와 서버, 조회한 잔액, 처리 중인 서명과 거래, DApp 연결 정보.

매장 기록: 매장 서버 주소와 인증서, 고객 번호, 주문 번호와 상태, 금액, 매장 이름, 주문 확인용 열쇠의 씨앗값, 보낸 답, 알림 예약.

이전 방식의 대여 보드를 등록했으면 블루투스 주소, 이름, 지갑 주소.

여행 기능에서 녹음한 음성과 목록(최대 20건), 삭제 요청의 확인값.

지갑 기록과 주문 기록은 휴대전화의 보안 저장소 열쇠로 암호화합니다. 대여 보드 목록, 매장 등록 정보, 알림 예약은 이 앱만 읽는 저장 공간에 둡니다. Android에서는 시스템 백업에 앱 자료를 넣지 않습니다.

## 보드와 주고받는 것

앱은 블루투스로 보드와 직접 통신합니다. 결제용 보드의 PIN은 보드에서만 입력하며 휴대전화로 오지 않습니다.

이전 방식의 대여 보드를 설정할 때는 보드가 입력 중인 PIN 숫자를 앱 화면에 보여 줍니다. 앱은 이 숫자를 저장하지 않습니다.

## 매장 서버로 보내는 것

주문할 때: 고객 번호, 매장 번호, 주문 품목과 수량, 금액, 예약 시각과 인원(예약할 때), 구독 동의와 변경.

결제할 때: 견적 식별값, 보드 서명, 보드 계정 주소와 세대, 주문 확인용 공개 주소.

전달 뒤: 수령, 이의, 이의 취소의 답과 서명. 반납할 때: 보드 계정 주소, 받을 주소, 금액, 기한, 서명.

매장 서버는 접속한 IP 주소를 볼 수 있습니다. 매장에서 블루투스로 주문하면 같은 내용이 매장 기기를 거쳐 갑니다.

## 체인과 조회 서버

잔액과 거래를 읽으려고 앱은 선택한 조회 서버에 지갑 주소를 보냅니다. 그 서버는 지갑 주소와 IP 주소를 함께 볼 수 있습니다. 개인 전송을 하면 서명한 거래도 보냅니다.

앱이 처음에 쓰는 서버: api.test.stablenet.network, ethereum-sepolia-rpc.publicnode.com, base-sepolia.gateway.tenderly.co, mempool.space, api.devnet.solana.com, s.altnet.rippletest.net. 이 서버들은 다른 곳이 운영하며 각자의 방침을 따릅니다. 설정에서 서버를 바꿀 수 있고, 매장이나 운영자가 다른 서버를 정할 수 있습니다.

결제, 수령, 이의, 반납을 하면 주소, 금액, 시각, 무작위 주문 번호가 공개 체인에 남습니다. 누구나 볼 수 있고 지울 수 없습니다.

## 선택 기능에서 보내는 것

DApp 둘러보기: 방문한 사이트가 IP 주소를 보고, 연결을 승인하면 지갑 주소를 봅니다. 앱은 쿠키와 위치 요청을 막습니다.

다른 앱 연결(WalletConnect): 중계 서버가 IP 주소와 암호화된 메시지를 받습니다.

여행 정보: 공개 정보 서버가 검색한 지역과 지도 구역, IP 주소를 봅니다. 동의한 경우에만 음성, 전사 요청, 일정, 후기, 방문 확인을 여행 서버로 보냅니다.

클라우드 지갑: 배포에 설정된 경우에만 쓸 수 있습니다. 로그인 제공자와 지갑 서버가 로그인과 서명에 필요한 값을 받습니다.

시험 시장: 실습용 지갑 주소와 거래가 시험 시장 서버와 체인으로 갑니다.

공유 버튼을 누르면 화면에 보인 내용을 사용자가 고른 앱으로 보냅니다.

## 권한

블루투스: 보드와 매장 찾기와 연결. 카메라: QR 읽기. 읽은 사진은 앱이 저장하지 않습니다. 마이크: 여행 음성 녹음. 알림: 주문 준비와 구독 알림. 알림은 휴대전화 안에서 만들고 외부 알림 서버를 쓰지 않습니다.

권한을 거절해도 그 권한이 필요 없는 기능은 쓸 수 있습니다.

## 보관 기간과 삭제

휴대전화의 기록은 앱을 지우면 함께 지워집니다. iOS는 앱을 지운 뒤에도 보안 저장소에 일부가 남을 수 있습니다.

보드를 초기화하면 보드의 열쇠, PIN, 등록이 지워집니다. 끝난 주문 기록은 휴대전화에 남습니다.

매장 서버의 주문과 결제 기록 보관 기간: {{retention.storeOrders}}. 서버 접속 기록 보관 기간: {{retention.serverLogs}}. 여행 서버 기록 보관 기간: {{retention.travelRecords}}.

체인 기록은 지울 수 없습니다.
