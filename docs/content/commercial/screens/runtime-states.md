# 화면 상태별 실행 증거 등록표

설계 화면의 상태 식별자 461개에 제품 UI의 검증 결과를 연결한다. **관측** 열은 실제 브라우저나 모바일 앱을 조작하고 해당 상태의 기능을 확인한 기록이다. **증거 연결 대기**에는 같은 상태에 대한 UI 증거를 장부에 등록해야 하는 항목을 적는다. 작업별 서비스·펌웨어·컴포넌트 시험과 접근성 결함은 [화면 인수 현황](runtime-acceptance.md)에 따로 기록한다.

식별자를 클릭하면 해당 설계와 다음 행동을 확인할 수 있다. 구현자는 완료한 행동, 제품 빌드, 실행 조건, 결과를 제출하고 검수자는 같은 상태에서 업무 원장과 사용자 표시를 대조한다.
