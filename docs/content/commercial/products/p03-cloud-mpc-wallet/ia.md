## 진입 구조와 접근 권한

사용자 접점은 P02의 선택형 지갑 화면이다. 이 제품은 참여자 저장소, 서명 세션, 복구 운영 조회 권한을 가진다.

| 상위 → 하위 | 보이는 정보와 가능한 조작 | 접근 조건과 오류 시 이동 |
|---|---|---|
| 계정 → 클라우드 지갑 → 생성/연계 | 인증수단·공개 주소·생성 결과 | 사용자만 연계, 중단 시 생성 세션 조회 |
| 지갑 → 승인 요청 → 라운드 결과 | 체인·지출·세대·결과 식별자 | 현재 사용자 참여자만 승인, 만료 시 목록 복귀 |
| 복구 → 대상 계정/새 기기 → 진행 상황 | 대기·승인·활성 확인·통지 | 신청자와 독립 승인자 권한 분리, 실패 시 보류 |
| 운영 → 감사/서비스 상태 | 세션 참조·정책 버전·원인 코드 | 조각 원문은 참여자 격리 저장소에서만 사용 |

## 정보 객체와 관계

소셜 신원과 지갑 계정을 분리한다. 한 계정에 참여자 집합 버전, 서명 세션, 복구 요청이 연결된다. 업무 DB에 공개키·역할·transcript digest만 기록하고 조각과 일회 서명 자료는 분리한다.

## 상태와 복귀 위치

생성 대기 → 부분 준비 → 활성 → 복구 동결 → 교체 검증 → 새 세대 활성. 소셜 로그아웃은 인증 세션을 종료한다. 지갑의 키 삭제나 소유권 이전은 별도 절차다.

### 복구 담당자 조회

W24에서 B 지연과 정족수 유출 신고를 구분해 선택한다. 마지막 가용 시각, 정책 버전, 서명 동결 여부, 대체 경로 인수 여부와 사고 식별자를 표시한다. 유출 신고가 있으면 기존 키 위험과 사용자 동의 이전 상태를 별도로 남긴다. 고객의 생성·서명·복구 화면 W20–W22와 운영 감사 조회 권한을 분리한다.
