## 제공 순서와 책임

처음에는 테스트 계정의 생성과 서명만 제공한다. 복구와 세대 교체를 통과한 지원 조합부터 온보딩 선택지로 노출한다.

| 단계 · 책임 | 선행 조건과 작업 | 다음 단계로 넘어갈 증거 |
|---|---|---|
| 보안 설계 · 참여자 구성 | A/B/C 후보의 관리자·키 저장소·백업·복구 승인권을 조사 | 주체별 권한표와 합의한 장애·결탁 모델 |
| 지갑 서비스 · 생성/승인 | P02에서 클라우드 지갑 명시 선택과 DKG, 일회성 승인 연동 | 동시 생성·중복 서명·부분 실패의 상태 조회 |
| 복구 운영 · 세대 교체 | 서명 차단, 재등록, 참여자 ACK, 감사와 계정 종료 구현 | 분실 폰·서비스 중단·직원 단독 복구 거절 훈련 |

## 전환과 장애 대응

생성·서명·복구는 다른 작업 식별자를 사용한다. 중단한 임계 라운드의 일회 자료를 새 원문에 재사용하지 않는다. 이미 완성된 서명은 별도로 추적하고 미완료 교체는 잠금 상태에서 재개한다.

## 결정이 필요한 항목

C의 운영 주체, 사용자 증명, 복구 대기와 통지 수단, 체인별 임계 엔진의 지원 범위를 선정한 뒤 각 프로필을 활성화한다.
