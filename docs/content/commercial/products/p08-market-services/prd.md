## 사용자와 결과

학습 사용자가 StableNet 테스트 자산으로 교환, 유동성 공급, 모의 환전 및 파생상품 포지션의 변화를 확인한다. 운영자는 가격 이상과 중복 정산을 통제한다.

## 현재 출발점과 목표 범위

기존 제품은 설계 전용이다. 이 기능군은 매장 직접 지급과 분리된 선택형 테스트넷 실습이며 상용 자산이나 메인넷 거래를 여는 계획은 별도 결정이 필요하다. [제품 README](../../../../../products/p08-market-services/README.md) · [시장 상품 상세 설계](../../../specifications/market-product-design.md)

## 기능과 인수 조건

| ID | 기능 | 제품이 보장할 동작 | 인수 시 관측할 결과 |
|---|---|---|---|
| R1 | 교환·유동성 | AMM 경로, 수수료, 최소 수령/최대 지급과 기한을 보여주고 LP 추가·제거 시 예상 지분과 실제 결과를 대조한다. | 유효 범위 밖 가격에서는 실행 0건. 중단 후 같은 해시를 조회해 중복 포지션 생성 0건. |
| R2 | TEST FX | 통화쌍·방향·소수 단위·가격 시각·기한을 명시하고 한 견적에 한 실행만 연결한다. | 기간 만료 또는 역방향 혼동을 거절하고 재견적에 사용자 재동의를 받는다. |
| R3 | 무기한 포지션 | 증거금·방향·한도·가격 기준, 펀딩 시점·예상 청산 조건을 표시하고 포지션별 이력을 남긴다. | 같은 기간 펀딩 중복 0건, 청산과 사용자 청산 방지 주문 경합에서 이중 정산 0건. |
| R4 | 가격·keeper 운영 | 가격 출처와 신선도·이상 상태를 검증하고 keeper 작업을 멱등 실행한다. | 오래된 가격으로 신규 위험 증가나 자동 청산 0건. 정상화 후 재개 근거와 정산 이력을 조회. |

## 출시 판단

테스트넷 환경 표시, 검증된 가격 정책, 손익·수수료·보유량 대사, 각 상품의 실행 중지·재개 훈련을 통과할 때만 학습 메뉴를 연다. 매장 결제 SLA에는 의존성을 추가하지 않는다.
