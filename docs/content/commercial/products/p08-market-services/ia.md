## 진입 구조와 접근 권한

학습 화면에는 네트워크와 테스트 자산임을 일관되게 표시한다. 모바일은 거래 입력·결과, 운영 화면은 가격 및 keeper 권한을 소유한다.

| 상위 → 하위 | 보이는 정보와 가능한 조작 | 접근 조건과 오류 시 이동 |
|---|---|---|
| 학습 → 교환/LP → 견적·풀 상세 | 경로·비용·최소 수령·지분 추가/제거 | 테스트 지갑, 기한 경과 시 입력값을 유지해 재견적 |
| 학습 → TEST FX → 방향/결과 | 기준/상대 통화·금액·가격 시각 | 확정 전 방향 전환 시 새 동의 |
| 학습 → 포지션 → 내역/펀딩/청산 | 증거금·진입 가격·평가 기준·실현 결과 | 본인 요청만 실행, 가격 이상 시 보류 |
| 운영 → 가격 소스/keeper/재생 | 신선도·정산 키·작업 결과 | 운영 역할 제한, 재생은 같은 포지션·기간 기준. 체인 결과는 P07/시장 관측기에서 확인 |

## 정보 객체와 관계

상품·시장·풀·테스트 토큰을 체인/계약과 연결한다. 견적은 가격 버전과 한도, 포지션은 증거금과 펀딩 이력을 갖는다. 매장 주문·스탬프·구독 원장과 분리한다.

## 상태와 복귀 위치

견적 생성 → 승인 대기 → 제출 → 확정/실행 거절. 포지션은 열림 → 일부 축소/펀딩 → 종료 또는 청산. 가격 피드 중지는 개별 포지션의 종료를 뜻하지 않는다.

## 화면별 검토와 복귀

교환은 경로·수수료·최소 수령·기한, LP는 추가 또는 제거의 예상 지분과 실제 잔액, TEST FX는 통화 방향·소수 단위·가격 시각을 표시한다. 기한 만료나 방향 변경에는 새 견적과 사용자 동의가 필요하다. 제출 결과가 불명확하면 기존 해시를 조회한다. 포지션에는 증거금·방향·한도·가격·펀딩·예상 청산 조건과 이력을 표시하고 가격 중지는 포지션 종료와 구분한다. 운영자 화면은 가격 신선도, 작업 키·포지션 버전·기간, 기존 해시와 정규 체인 대조 결과를 표시한다. 모든 학습 화면에서 테스트넷과 테스트 자산을 식별한다.
