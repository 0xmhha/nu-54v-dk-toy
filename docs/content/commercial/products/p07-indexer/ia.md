## 진입 구조와 접근 권한

탐색 프런트엔드 목표는 네트워크/배포 선택 → 가맹점·주문 검색 → 영수증 상세 → 검증 블록/트랜잭션으로 이어지는 읽기 전용 탐색이다. 미색인과 노드 지연을 구분하고 이 화면에서 환불·재발행을 실행할 수 없다. 서비스 내부에서는 조회 영역과 수집 운영 영역에 다른 접근 권한을 부여한다.

| 상위 → 하위 | 보이는 정보와 가능한 조작 | 접근 조건과 오류 시 이동 |
|---|---|---|
| 조회 → 매장/주문 → 지급·환불 | 금액·토큰·계약 버전·블록·확정도 | 공개 체인 증거와 가맹점 전용 주문 메타데이터 분리 |
| 상태 → 체인/배포 → 동기화 | 마지막 확정 높이·시각·누락 구간 | 운영자 상세, 고객에 최신성 표시 |
| 운영 → 재생/검증 → 전환 | 시작 커서·대상 ABI·대조 차이 | 인가된 운영자와 변경 감사, 차이 시 기존 조회 유지 |
| 사고 → 분기/불일치 → 대사 | 영향받은 주문·근거 해시·조치 | 재무·운영 담당에게 제한, 조사 결과를 P05에 통지 |

## 정보 객체와 관계

미색인·관측 지연·확정 충돌 화면은 원 배포 범위와 마지막 관측 높이·시각을 유지한다. 확정 미지급 근거는 만료 경계 이후까지 연속된 정규 구간과 계약 미소비를 대조한 뒤 업무 원장으로 전달한다. 미등록 ABI는 해당 후보만 보류하고 운영자 화면에 구성과 사유를 표시한다. 승인 서명이 검증된 동일 배포가 다시 등록되면 보류를 해제한다. 재생 작업은 운영 조회에서 지정한 확정 높이와 revision을 기준으로 별도 후보에 기록한다. 인가된 운영자는 시작한 작업 ID로 재조회할 수 있다. 불일치하면 기존 조회를 유지한다. 대조가 일치한 뒤에도 기존 전환 권한이 검증 증거와 revision을 확인해야 활성 대상이 바뀐다. 운영자가 새 대상을 요청한 시각과 실제 활성화된 시각·감사 ID를 따로 표시한다. [공개 영수증과 범위 조회](../../screens/book.html#X02) · [운영 전환](../../screens/book.html#X05)

이벤트의 물리적 식별자는 체인·계약·블록 해시·트랜잭션 해시·로그 인덱스다. 업무상 조회 키는 가맹점·주문·버전이다. 관측 체크포인트, 지급 투영, 환불 투영을 증거로 연결한다.

## 상태와 복귀 위치

미동기화 → 따라잡기 → 정상 → 지연/분기 조사 → 재생 → 정상. 개별 지급의 미관측·포함·확정과 인덱서 자체 상태는 독립해 표시한다.
