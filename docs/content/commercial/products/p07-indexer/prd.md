# P07 체인 인덱서·영수증 조회 · 제품 요구사항

[제품별 설계 목차](../README.md) · [PRD](prd.md) · [기획](plan.md) · [유즈케이스](use-cases.md) · [정보구조](ia.md)

## 사용자와 결과

고객과 점주가 원주문의 실제 체인 지급·환불을 확인하고, 운영자가 노드 장애나 체인 재구성 뒤에도 동일한 원장에서 대사할 수 있게 한다.

## 현재 출발점과 목표 범위

Go 수집기·저장소·영수증 조회가 v1 지급 이벤트를 취급한다. 신규 직접 지급/환불 이벤트, 다중 배포, 누락 구간 복구와 관측 상태를 명시적으로 도입한다. [제품 README](../../../../../products/p07-indexer/README.md) · [수집·저장·영수증 코드](../../../../../products/p07-indexer/internal) · [결제 확정과 대사](../../merchant-payments.md)

## 기능과 인수 조건

| ID | 기능 | 제품이 보장할 동작 | 인수 시 관측할 결과 |
|---|---|---|---|
| R1 | 대상·커서 | P10 manifest의 체인·주소·ABI·시작 높이를 기준으로 수집하고 이벤트와 커서를 함께 기록한다. | 페이지 중간 강제 종료·중복 로그에도 같은 확정 이벤트 집합을 산출한다. |
| R2 | 확정·재구성 | 관측 블록의 해시·부모와 체인별 확정 정책을 검사한다. 비정상 분기·노드 불일치는 마지막 공통 지점부터 정합성을 복구한다. | 제거된 미확정 이벤트가 확정 영수증에 남는 건수 0, 확정 가정 위배는 사고 상태로 승격. |
| R3 | 영수증 조회 | 가맹점·주문·체인·계약 버전별 지급, 부분 환불과 최신 관측 높이를 반환한다. 기존 v1 조회를 유지하고 읽기 전용 탐색 화면에 검색·검증 블록·확정도·최신성 및 조회 권한을 제공한다. | 두 매장의 같은 주문 번호가 섞이지 않고 조회 없음·동기화 지연·확정 지급을 구분한다. |
| R4 | 대사·재생 | 원시 체인 식별자와 증거를 P05에 전달하고 체크포인트부터 재생한다. 업무상 취소·조리 결정은 P05가 수행한다. | 독립 재색인과 원장 이벤트 총액 일치. 중복 전달은 추가 이행 0건. |

## 출시 판단

v1·v2 동시 수집, 만료 직전 포함 후 늦은 확정, 노드 전환, 저장 중 재시작을 기록한 뒤 결과를 독립 조회한 체인 데이터와 대조한다.
