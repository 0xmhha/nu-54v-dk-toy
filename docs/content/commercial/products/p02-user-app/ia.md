## 진입 구조와 접근 권한

하단 탐색은 홈·결제·지갑·둘러보기·설정으로 구성한다(결정 2026-11-24). 홈은 대시보드로 보드 상태와 오늘 남은 한도, 할 일, 네트워크 상태, 최근 활동만 보이고 잔액과 주소는 지갑 탭에 둔다. 내 보드는 홈의 보드 카드와 설정에서 열며 설정 탭에 속한다. 필수 동의를 마치기 전에는 어느 탭도 열리지 않는다. 보드 승인은 어느 진입점에서든 같은 확인 화면을 사용한다. 상용 제안 화면은 기존 구현과 구분해 관리한다.

| 상위 → 하위 | 보이는 정보와 가능한 조작 | 접근 조건과 오류 시 이동 |
|---|---|---|
| 홈 → 보드 카드·할 일·바로 가기·상태 | 보드 상태, 오늘 남은 한도, 주문번호와 남은 확인 기간 | 보드 설정 전이면 보드 설정으로, 주문은 결제 → 주문 상세로 |
| 내 보드 → 보드 설정·입금·반납·초기화·LED 신호 | 서명 시험, 반납받을 주소, 한도, 운영자 허가 상태 | 서명 시험 전에는 입금 주소를 보이지 않는다. 끝나지 않은 주문이 있으면 반납과 초기화를 막는다 |
| 지갑 → 네트워크 → 토큰 → 받기·반납·시험 토큰·토큰 추가 | 선택한 네트워크의 잔액과 계약 주소, 보드가 보낼 수 있는지, 활동 | 보드가 보낼 수 없는 네트워크와 토큰은 보기만 하고 받기 주소를 보이지 않는다. 초기화 전에 보낼 수 없는 자산을 하나씩 확인한다 |
| 설정 → 네트워크 → 추가·변경·숨기기·삭제 | 서버 주소와 출처, 연결 상태, 탐색기 | 체인 ID와 첫 블록이 맞는 서버만 저장한다. 앱에 있는 네트워크는 숨길 수만 있다 |
| 설정 → 법적 고지 → 문서·오픈소스 라이선스·동의 기록 | 판과 시행일, 책임 주체, 라이선스 전문 | 문서의 판이 바뀌면 다시 동의를 묻는다 |
| 지갑(개인 HD 보드) → 계정/네트워크/자산 → 받기·보내기 | 전체 주소·태그, 수수료·잔액 시점, 원문 기반 확인 | 잠금 해제, 백업 상태 확인, 잘못된 네트워크는 해당 선택으로 복귀 |
| 결제 → 주문·예약/구독·미결/영수증 | 회차별 금액, 기한, 승인·거절, 디파짓·잔금·픽업, 받았어요·못 받았어요 | 푸시·딥링크도 권한 재조회, 불명은 기존 요청 상세로 |
| 둘러보기 → DApp 브라우저/연결 목록 | 출처, 선택 계정, 허용 체인·메서드, 로그인·지출·해제 | 출처가 바뀌면 새 동의, 거절 시 사이트로 결과만 반환 |
| 둘러보기 → 여행 지도/목록 → 장소/예약 | 지역 직접 입력, 거리·재고·가격, 미리 주문·취소 | 위치 미허용 시 수동 탐색, 예약 진행 상태는 결제 → 예약 상세로 |
| 설정 → 기기/보안/네트워크/도움말 | 본딩·복구·커스텀 체인·테스트넷, 알림·접근성·튜토리얼 다시 보기 | 기기 PIN·시드는 폰 입력 항목에서 제외, 미결 작업으로 돌아가기 제공 |
| 지갑 → 지갑 선택 → 클라우드 생성/승인/복구 | P03 출시 조합에서 소셜 계정 연계, DKG·별도 모바일 승인·복구 잠금 상태 | 지갑 종류를 고정해 표시하고 보드 서명으로 자동 대체하지 않는다. 중단한 작업은 같은 P03 세션으로 복귀 |
| 둘러보기 → 학습 → 교환/LP·FX·포지션 | P08 지원 테스트망에서만 보이는 학습 메뉴와 원장 결과 | 미출시 상품은 숨기고 저장한 딥링크는 미지원 이유를 안내한다 |
| 둘러보기 → 내 여행 / 설정 → 개인정보 | P09 발자취·AI 코스·후기, 목적별 동의 철회·삭제 작업 조회 | 사용자별 자료만 표시한다. 철회 후 진행 중 예약은 결제 탭에서 조회 |
| 지갑 → 계정 → 공개정보/권한 관리 | xpub/descriptor 내보내기, EVM allowance 조회·철회와 DApp 세션 해제를 구분 | 온체인 철회는 별도 거래 상세에서 확정까지 조회 |
| 설정 → 계정/기기 업데이트 | 선택형 Google·Apple 계정 연계/해제, 보드 FOTA 진행과 재개 | 개인 하드월렛 생성에는 소셜 가입을 요구하지 않는다. 마지막 인증수단 제거 방지, 업데이트 중단 시 원래 버전 확인 |
| 설정 → 기기 → 대여 보드 반납 상태(W12) | 수락한 대여 계정의 미결 지급 수와 미결 한도 변경 수, 조회 기준 시각·유효기한. 미결 지급 행에서 해당 대여의 원거래로 이동 | 고객 인증과 인도 수락이 유효해야 한다. 대여자 변경·백그라운드 전환·증거 만료 시 이전 값을 지우고 다시 조회한다. 대여 계약이 확인한 거래만 열 수 있다. |

## 정보 객체와 관계

프로필 아래 계정·체인·자산, 출처별 세션, 회차/예약별 주문 참조를 연결한다. 화면에서 선택한 심볼 대신 체인과 토큰 식별자로 조회한다. 주소록, 복구 자료, 여행 동의의 보관·삭제 권한을 분리한다.

## 상태와 복귀 위치

읽기 → 요청 검토 → 기기 대기 → 서명됨 → 제출 중/결과 미확인 → 확정·거절·만료. 뒤로 가기와 앱 종료는 결제 취소의 증거가 아니다. 다시 열면 원래 주문·해시를 조회하고 재청구를 막는다.
