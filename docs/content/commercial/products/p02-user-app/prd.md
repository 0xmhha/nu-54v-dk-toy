## 사용자와 결과

처음 보드를 산 사용자는 폰으로 설정부터 첫 입금까지 마치고, 여행자는 같은 앱에서 장소를 찾고 하드월렛으로 주문한다. 앱은 거래 내용을 표시하고 보드는 키와 최종 물리 승인을 소유한다.

## 현재 출발점과 목표 범위

기존 React Native 앱은 대여 기기 본딩과 결제 확인 중심이다. 아래 개인 지갑, 상용 iOS·Android UX, 브라우저·구독·여행은 개발 대상이다. [제품 README](../../../../../products/p02-user-app/README.md) · [앱 소스](../../../../../products/p02-user-app/src) · [지갑·모바일 상세 설계](../../wallet-and-mobile.md)

## 기능과 인수 조건

| ID | 기능 | 제품이 보장할 동작 | 인수 시 관측할 결과 |
|---|---|---|---|
| R1 | 설정·튜토리얼 | 보드 등록, 보드 PIN 설정, 백업 확인, 데모 자산 첫 송금을 단계별 안내한다. 건너뛰기·다시 보기와 화면 읽기를 지원한다. | 처음 사용자 테스트에서 보호자 없이 첫 테스트 결제를 완료하고 큰 글씨 200%·색상 없이도 거절할 수 있다. |
| R2 | 지갑·자산 | 계정과 네트워크를 명시하고 수신 QR·주소, 잔액·내역·수수료, 보내기와 상태 조회를 제공한다. | Bitcoin·Ethereum·Solana·XRPL·Base·StableNet 각각 수신·송금·거절 시험, 잔액과 수수료 단위 일치. |
| R3 | 네트워크 관리 | 체인·토큰 선택, 테스트넷 전환, 같은 엔진의 커스텀 네트워크·RPC 추가, 미지원 엔진 차단을 제공한다. | 잘못된 체인 ID/RPC 조합을 거부하고 메인넷·테스트넷 자산 합산 0건. |
| R4 | DApp 브라우저 | 내장 브라우저와 WalletConnect 연결 요청에서 출처와 권한을 보여주고 접속, SIWE 등 로그인 메시지, 거래·토큰 승인, 세션 해제를 각각 처리한다. | 연결만으로 서명 0건. 만료/출처 변경 후 재승인, 권한 철회 뒤 새 요청 거부. |
| R5 | 구독 | 약관·회차·금액·기한을 보여주고 알림이나 미결 목록에서 해당 청구서를 열어 매회 보드로 승인한다. | 알림 2개/폰 2대에도 한 회차 지급 최대 1건. 미승인 회차 지급 0건, 해지 후 미래 청구 0건. |
| R6 | 매장·여행 | 지도 검색, 시간대·인원 예약, 디파짓과 잔금, 미리 주문, 픽업·영수증·환불 조회를 제공한다. | 예약금 10과 잔금 20인 총액 30 주문에서 누계 30, 위치·푸시 거부 상태에서도 수동 검색·진행 가능. |
| R7 | 표시·분실 대응 | 기기 계산 요약과 실제 지급 대상·체인·수수료를 표시한다. 신뢰 경로가 필요한 거래를 정책에 따라 차단하고 폰 교체/분실 복구를 안내한다. | 폰 화면만 있는 고위험 요청은 거절되고, 새 폰 등록 후 구 폰 본드로 승인 0건. |
| R8 | 계정·공개정보·보호 설정 | 계정 재발견, 주소록, 계약별 자산 검색·즐겨찾기·숨김·재표시, 토큰 단위와 환산 시세의 출처·통화·갱신 시각 확인, 읽기 전용 내보내기와 허용목록 변경을 제공한다. | 숨긴 자산을 다시 표시해도 확정 잔액·미결 거래 참조가 같고 오프라인 시세에는 캐시 시각이 남는다. 숨긴 계정을 원래 경로에서 복구한다. 읽기 전용 프로필 서명 0건, 폰 단독으로 한도 상향 0건. |
| R9 | 단말과 계정 유지관리 | 배포 프로필과 실행 버전을 확인하고 충돌 작업을 표시한다. 진단 내용을 공유 전에 보여준다. 계정 로그아웃·탈퇴·개인 슬롯 초기화를 구분한다. | 업데이트 중단 후 실행 버전을 대조하고 미결 지급을 다시 조회한다. 진단 미리보기에 PIN·시드가 없고 탈퇴 시 자산 이동 0건. |

## 출시 판단

최소 수직 흐름은 Android/iOS에서 첫 설정 → 지정 테스트넷 결제 → 영수증 재조회다. 각 OS의 BLE 권한 거부·백그라운드 복귀와 재승인, 접근성 실기록을 확보한 조합만 지원 목록에 싣는다.
