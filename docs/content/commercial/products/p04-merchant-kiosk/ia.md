## 진입 구조와 접근 권한

공용 고객 화면, 본인 폰의 근거리 화면, 로그인한 직원 화면을 분리한다. 결제 전용 모드의 루트는 POS 금액이며 메뉴 탐색을 표시하지 않는다.

| 상위 → 하위 | 보이는 정보와 가능한 조작 | 접근 조건과 오류 시 이동 |
|---|---|---|
| 고객 → 카테고리/메뉴/옵션 → 장바구니 | 가격·재고·알레르기·언어·합계 | 세션별 접근, 품절 시 해당 항목으로 복귀 |
| 공용 메뉴 → 내 폰에서 주문하기 → 공용 장바구니 | 인증된 매장·단말 이름과 입구 QR을 보여 준다. 다른 고객이 폰으로 입구 QR을 읽으면 별도 장바구니를 연다. | 안내를 닫은 고객은 기존 옵션·수량으로 돌아간다. |
| 장바구니·주문 미리보기 → 종료 확인 → 계속 주문 또는 화면 지우기 | 계속 주문하면 원래 화면의 수량·옵션을 복원한다. 종료하면 다음 고객의 빈 화면을 연다. | 폰에 인계된 원주문·견적의 재조회는 인계받은 폰에서 한다. |
| 근거리 → 매장 확인/내 장바구니 → 결제 | 매장·주문 ID·잔여 기한, QR 또는 BLE | 단말이 고객별로 릴레이, 다른 고객 데이터 접근 거절 |
| POS → 결제 대기/지급자 선택 → 결과 | 외부 주문 참조·정확한 금액·지정 토큰 | 인증 POS·권한 직원, 중복 참조는 원주문으로 |
| 직원 → 주문 대기열/픽업/단말 설정 | 확정 여부·조리 번호·영수증 재출력·모드 전환 | 점원은 조리, 관리자만 모드 변경·단말 재등록. 인계와 버전 ACK 누락은 전환 대기 |
| 점주 → 매출·정산/원주문/환불 | 지점별 실입금·미결·부분 환불과 P05 상세 | 인증된 점주만 해당 지점 접근. 환불 요청을 승인·지급과 따로 표시 |

## 정보 객체와 관계

단말은 merchant/branch/terminal 식별자에 귀속한다. 원격 고객별 세션에 장바구니를 연결하고 외부 주문 참조·서명 견적·주문·지급 해시를 P05 기준 ID로 연결한다. 공용 화면에는 개인 주소·다른 고객 주문 상세를 표시하지 않는다.

## 상태와 복귀 위치

메뉴 탐색 → 예약 → 지급자 선택 → 견적 발행 → 승인/전송 → 확인 중 → 확정 → 준비/픽업. 결제 전용 단말은 금액 수신부터 시작한다. 발행 후 이탈한 주문은 미결 목록에서 서버 만료 처리 결과를 조회한다.

## 화면 전이와 재진입

공용 메뉴·옵션·장바구니에서 결제 전 품절과 가격 변경을 각각 처리한다. 공용 종료는 신규 주문 초기 화면으로 돌아가고 개인 주문은 폰의 지갑·근거리 매장 찾기에서 계속한다. 인증된 POS는 미리보기 → 후보 표식 비교 → 결합 조회 → 고객 승인 대기를 표시한다. 폰 연결 끊김, 중복 외부 참조, 만료 가능성이 있으면 원주문 조회로 돌아간다. 직원 대기열은 미확정 지급, 준비 중, 픽업 가능, 전달 완료를 분리하고 프린터 장애의 재진입점에 동일 영수증 ID를 표시한다.
