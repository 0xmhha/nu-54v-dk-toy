- [영문판](https://medium.com/@bc.0x4861/nu-54v-dk-02-hardware-wallet-private-keys-secure-elements-vs-trustzone-65c931f581c3): `[NU-54V-DK 02] Hardware Wallet Private Keys: Secure Elements vs TrustZone`
- 사용자 요청에 따라 두 판본을 검토하고 공개 발행했습니다. 각 판본의 발행 완료 메시지와 공개 페이지를 확인했습니다.
- 제목·부제, INDEX 6개와 본문 섹션, 출처 링크, 이전 편 링크를 넣었습니다.
- 각 판본에 이미지 4장을 실제 업로드했습니다. 대표 이미지는 공용, 설명 도식은 해당 언어 판본입니다.
- 각 이미지 아래에 이탤릭 캡션과 출처, 설계·개념도 여부를 명시했습니다.
- 원문 주제 태그 5개를 설정했습니다: NUCODE, 누코드, NU54VDK, 누코더스, Nucoders. Medium에서는 일부 영문 태그의 대소문자가 표준화되어 표시됩니다.
- 새로고침 후 각 판본의 이미지 4장 모두 Medium CDN에서 정상 로드됨을 확인했습니다.
- 새로고침 후 주제 태그 5개가 각각 유지됨을 확인했습니다.
- 두 원고의 문단·제목·캡션·목록·출처 63개 항목을 저장된 본문과 대조했습니다. 영문 자동 따옴표 변환과 공백을 정규화했을 때 누락이 없습니다. 비교 표는 Medium에서 동일 내용을 제품별 문단으로 표시합니다.
- [한글판 준비 화면](assets/02/medium-draft-ko.png), [영문판 준비 화면](assets/02/medium-draft-en.png)을 저장했습니다.
- 후속 글이 발행되면 다음 편 링크를 넣습니다.
- 사용자 요청에 따라 한글·영문 원고와 Medium 초안에서 레퍼런스 7의 프로젝트 저장소 링크를 제거했습니다. 새로고침 후 링크가 없는 Draft Saved 상태를 확인했습니다. 저장소는 시리즈 마지막 편에서 공개합니다.
- 출처 정리 확인 화면: [한글판](assets/02/medium-references-ko.png), [영문판](assets/02/medium-references-en.png).
- 발행 전 공식 자료와 일정·펌웨어 기록을 재검토하고, 두 원고와 Medium 본문에 누락이 없는 것을 확인했습니다.
- 공개 페이지에서 판본별 이미지 4장의 정상 로딩, 태그 5개 유지, 프로젝트 저장소 링크 제외를 확인했습니다.
