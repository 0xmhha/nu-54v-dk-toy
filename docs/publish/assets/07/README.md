# 07편 이미지 제작 기록

- 제작일: 2026-11-09.
- `build-diagrams.py`로 한글·영문 각 3장, 총 6장을 직접 작성했습니다. PNG는 모두 1600×1100입니다.
- 06편의 그리기 도우미와 같은 서체·색을 재사용합니다. 원고에는 각 언어의 상대 경로와 이미지 바로 아래 이탤릭 캡션을 넣었습니다.
- 실제 구현 코드·배포 설정·기존 시험을 설명하는 도식입니다. 실기 반납·지급이 모두 완료됐다는 결과 사진이 아닙니다.
- 그림 1의 출금 대기는 closeAccount가 실행된 블록 시각부터 시작합니다. 초기화는 별도로 AccountClosed의 확정을 기다립니다. 화살표와 상자 간격은 시간에 비례하지 않습니다.
- 그림 2의 0~3600초 축은 배포 설정의 지연을 비례 표시합니다. 눈금 0, 900, 1800, 2700, 3600은 같은 간격입니다. 각 행의 0은 해당 함수 실행 시각입니다. 시간 경과만으로 지급된다고 표시하지 않습니다.
- 그림 3은 중단 지점별 동작과 응답 유실의 미완료 처리를 나타냅니다. 오류 비율이나 측정 건수를 만들지 않았습니다.
- 실제 주소·해시·키·계정·내부 경로·프로젝트 저장소 링크는 이미지에 없습니다.
