# 06편 이미지 제작 기록

- 제작일: 2026-11-09.
- `build-diagrams.py`로 한글·영문 각 3장, 총 6장의 PNG를 직접 작성했습니다. 모두 1600×1100입니다.
- 이전 편의 서체와 색을 사용했습니다. AI 생성 사진이나 가상의 앱 화면은 없습니다.
- 현재 코드·통신 규격을 바탕으로 한 개념도이며 제품 보안 인증·새로운 보드 실기 시험의 결과가 아닙니다.
- 그림 1의 보드는 화면이 없고 LED 4개와 버튼 4개를 갖춘 개략도입니다. 폰은 셋업 후의 passkey 본딩을 표시합니다. 최초 Just Works 셋업 예외는 본문에서 설명합니다.
- 그림 2의 세로 간격은 소요 시간에 비례하지 않습니다. 최초 요청·응답은 평문, 이후 키오스크 본문은 암호화입니다.
- 그림 3은 12바이트 IV를 같은 폭의 칸 12개로 표시합니다. C 구현은 방향 1바이트와 0 3바이트, 64비트 번호 8바이트를 사용합니다. 규격의 11바이트 번호 필드와 구분합니다.
- 본문 아래에 각 그림의 출처·해석 범위를 담은 캡션을 넣었습니다.
- 실제 키·주소·해시·계정·내부 경로·프로젝트 저장소 링크는 이미지에 없습니다.
