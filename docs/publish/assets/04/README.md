# 04편 이미지 제작 기록

- 제작·캡처일: 2026-10-19.
- 본문에는 실제 앱 캡처 2장과 한글·영문 도식 각 2장을 사용합니다.
- 앱 캡처는 Android API 34 에뮬레이터에서 현재 키오스크 앱을 실행해 원본 PNG로 저장했습니다. 앱 소스와 화면 문구를 변경하지 않았습니다.
- 가상 가게 `Cafe (Emulator)`, 일회용 시험 설정, 잔액 조회만 응답하는 로컬 서버를 사용했습니다. 실제 체인 제출·결제는 실행하지 않았습니다.
- 캡처는 10월 5일 실기 실행 당시의 증거가 아닙니다. 현재 앱 UI는 한글이므로 영문판에도 동일한 캡처와 영문 설명을 사용합니다.
- 도식은 `build-diagrams.py`로 직접 작성했습니다. AI 생성 이미지는 없습니다.
- 시간 인포그래픽은 공통 경과 시간축 위에 요청·약 5.5초 승인·7.1초 앱 결과를 배치합니다. 약 5.5초는 근삿값이고 두 값의 차이를 체인 지연으로 계산하지 않습니다. 1 tUSDC는 토큰 아이콘으로, 결제 포함 블록과 확인 시 확정 블록은 연결된 블록으로 표현합니다. 블록 간 간격은 비례하지 않습니다.
- 수치는 큰 글자만으로 나열하지 않고 시간·수량·단계의 관계를 시각화합니다. 원문에 없는 평균, 비율, 잔액이나 지연을 추가하지 않습니다.
- 실제 주소·해시·키·계정·내부 경로는 공개 이미지에 넣지 않았습니다.
