## 영문 공개 실수와 현재 상태

- 태그 설정을 위해 발행 전 화면을 여는 과정에서 동일한 Publish 버튼을 잘못 다시 눌러 영문 사본이 공개됐습니다.
- 잘못 공개된 사본: https://medium.com/p/50f91713ffaa (초안 링크가 아닙니다).
- Medium은 발행한 글을 초안으로 되돌리지 못합니다. 삭제는 영구 작업이라는 이유로 자동 승인 검토에서 거절되었습니다. 우회하지 않았습니다.
- 사본은 Manage unlisted setting → Yes → Save로 목록 비공개 전환했고, 다시 설정을 열어 링크를 가진 사람에게만 보이며 프로필·홈페이지에는 나타나지 않는다는 문구를 확인했습니다.
- 확인 화면: `assets/03/medium-en-unlisted.png`.
- 발행 당시 Medium은 “published and sent”를 표시했습니다. 이미 발송된 알림이나 이메일은 취소 여부를 확인할 수 없고 회수하지 못했습니다.
- 별도 영문 초안(7e10dd14ae5a)을 본문과 이미지 모두 복사해 준비했습니다. 삭제 승인을 사용자에게 요청한 상태이며, 승인 전에는 목록 비공개 사본을 삭제하지 않습니다.
- 한글판은 공개하지 않았습니다.
