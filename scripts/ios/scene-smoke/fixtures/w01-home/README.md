# W01 synthetic iOS home fixture

`Fixture.swift` writes a synthetic profile and one historical test observation to the Keychain of **only** `com.nu54renter.w01qa`. It contains no private key, real account or real asset. Do not use a real bundle identifier. The P02 candidate must be built with the same simulator application identifier and signed for the simulator. On a disposable simulator, compile the fixture for its simulator architecture with `-parse-as-library -module-name NU54Fixture` and link its `__TEXT,__entitlements` section to the candidate build's `NU54Renter.app-Simulated.xcent`; copy `Info.plist` into the fixture app, ad-hoc sign it, install and launch it. The fixture screen must turn green (Keychain status zero). Install the candidate over that same disposable bundle and run `SceneSmoke/WalletHomePrivacySmoke` in `SceneSmoke.xcodeproj`; use a new result bundle and `-collect-test-diagnostics never`. The test covers the Korean historical observation, persistent hidden state, English and background/foreground return. It does not claim proof about a real board or a physical device.
